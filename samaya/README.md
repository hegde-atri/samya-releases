# Samaya for Noctalia

Your Focus clock, meetings and Samaya controls in the bar.

See [README.org](README.org) for the canonical installation, settings,
reload, troubleshooting and removal guide. Requires native Noctalia 5.3.0
and a GUI build of Samaya 1.12.0 or later on the shell's PATH.

Add `https://git.hegdeatri.com/hegdeatri/samaya-releases` as a Git source in
Noctalia Settings → Plugins, enable Samaya, then add its Focus widget to a bar.

This display shim exists because Noctalia's plugin details view reads `README.md`.
