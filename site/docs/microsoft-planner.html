Microsoft Planner

The Microsoft Planner panel lists the Planner tasks assigned to you, across all your plans, from saved filters. Drag one onto a day to plan it as an org task. See GitHub for shared planning controls.

Account and sign-in

Planner has no token to paste. Samaya reads it through an Outlook account connected in Settings → Calendars, as described in Outlook calendars. Choose the account in Settings → Microsoft Planner; with only one connected, it is used.

  • A work or school account is needed. Microsoft offers Planner only to Microsoft 365 organizations, so a personal account (outlook.com, hotmail, live) can't list Planner tasks.

  • An account connected before Planner was supported needs reauthorizing once, from its card in Settings → Calendars or with samaya sync reauth, to grant Tasks.Read. Until then the panel says Microsoft refused.

  • Only basic plans are listed. Premium plans are not listed.

Filters

Manage saved filters in Settings → Microsoft Planner.

A filter's query is key=value pairs joined by &, and a value can be several, separated by commas:

ParameterFinds
status=notstarted,inprogresstasks with this progress: notstarted, inprogress or completed
priority=urgent,importanttasks with these priorities: urgent, important, medium or low
due=overdue,weektasks due before today, today, in the next 7 days (week), or not at all (none)
plan=Marketingtasks in the plan with this name
bucket=Next uptasks in the bucket with this name
search=launchtasks whose title contains this

Names are matched whatever their case. The defaults are:

NameQuery
Assigned to mestatus=notstarted,inprogress
Due this weekstatus=notstarted,inprogress&due=overdue,week

Results are soonest due first, then most urgent. Use ↻ to refresh the panel.

Planning a task

As on GitHub, a card dropped on a day becomes a task in Inbox.org, recorded as coming from Planner by the task's ID and its plan's name. Its card shows the plan and the task's bucket.

SCHEDULED: <2026-10-20 Tue>
:PROPERTIES:
:ID: ...
:EFFORT: 0:30
:SAMAYA_SOURCE_INTEGRATION: microsoft-planner
:SAMAYA_SOURCE_ITEM: ...
:SAMAYA_SOURCE_REFERENCE: Launch
:END:

Drag the task back onto the Planner panel to un-plan it. Samaya only reads Planner: completing the Org task leaves the Planner task as it is.
