Samaya 2

Samaya 2 is a redesign of the whole app. Over time the screens in version 1 had each ended up looking a bit different, so I rebuilt every one of them with the same colours, type, spacing and components. The icons are Iconsax now, which I really like. On top of that there's a command palette, you can set a capacity for each day of the week, and every card, panel, menu and dialog works from the keyboard.

Download Changelog

No breaking changes

  • Org files and their format haven't changed.
  • Settings in desktop.toml and sync.toml stay as they are. If you saved a value, it wins over any new default.
  • Calendars, integrations and accounts keep working, and you don't have to sign in again.

A few keyboard shortcuts did change, so have a look at Changed shortcuts. You'll get the update in Settings › Update, or you can run the installer again.

Sidebar and header

The sidebar has Plan and your channels, with Search and Focus at the top and sync status at the bottom. Ctrl \ folds it down to a rail of icons, and Focus folds it for you. Every screen also has the same header now, with its title, period, view and the toggles for its panels.

Today

Your tasks for the day, next to the day's calendar. The header shows how much you've planned against the day's capacity. Add task opens quick add right where you are, and every card works from the keyboard.

Version 1

Week

The header shows which period and view you're on, and all the filters are in one menu. The board's columns have a fixed width now. The time grids open at the first thing on your calendar, and you can zoom them with Ctrl and the scroll wheel. Month shows six weeks.

Channels

A channel shows its tasks grouped by day, then the backlog, then what's done. Add task (N) brings up quick add, and when you select a few tasks you get a bar of actions for them.

Version 1

Focus

Focus puts the task, its timer and its subtasks in one column. F starts and pauses, Space completes the task, and End focus saves the session without completing it.

Version 1

Task editor and quick add

The task editor is now a single list of properties: scheduled, estimate, logged, due, priority, channel and goal. Quick add is one card with the suggestions right in it. It opens under Add task, or next to a slot you drag out on a calendar.

Version 1

Goals

Every goal now has the same fixed columns, so they all line up. You see logged time against the plan, this week's habits, the next step and how the goal is doing. A goal's own page uses the same pieces.

Version 1

Progress

Progress shows how each goal is pacing over the year, with a line for today in your accent colour. You can step through habit days, weeks and bars with the arrow keys.

Version 1

Analytics

Analytics shows your focus by day, by channel and by hour. If a period isn't over yet, it's compared with the same number of days from the one before, so 1–25 Nov is compared with 1–25 Oct and not the whole month.

Version 1

Side panels and mail

Backlog, Sources and Outlook mail all have the same header and one-line rows now. Shift B and Shift S jump straight to the first row of the backlog or your sources. In mail, a conversation opens in a reading pane next to the panel, and Y archives it.

Settings

Settings really needed work. It now opens on an overview of every page, so you can see what needs your attention. The pages are grouped into Preferences, Sources, Data and About, and each source you connect gets its own row in Sources.

Version 1

Tray

The tray menu is in the same order as the app now, and it uses the new Samaya icon.

New

Command palette

Press Ctrl K to jump to a screen, channel, Settings page, task, event or goal, or to run an action. Before you type anything, it shows what you opened recently and a few things that make sense right now.

Settings › Planning

This is where you set a capacity for each day of the week, along with your shutdown time, your weekly review day and the day your week starts. Today and Week then compare what you've planned with each day's capacity.

Keyboard everywhere

The arrow keys move a highlight over cards, rows, panels, calendar bookings, days in Month, goals and charts. Every menu and dialog works from the keyboard, and menus show the key for each item. Press ? for the shortcut sheet, which you can filter.

Settings search and reset

Search finds any setting on any page. Settings you've changed are marked, and you can reset a single setting or a whole page.

One undo

Completing, deleting, moving and nesting tasks all show the same toast with Undo. Ctrl Z works too, and it shares one history with your calendar edits. If the Org file has changed since, undo won't go through, so it can't overwrite something you changed somewhere else.

Safer writes

If saving to an Org file fails, the change isn't lost. It's kept, the task gets marked, and you can retry right there. The bottom of the sidebar says “Not saved · Retry”. When you quit, Samaya waits for anything still saving and asks before it throws away a change that didn't save. Drafts in the editor also survive if the file gets edited outside Samaya.
