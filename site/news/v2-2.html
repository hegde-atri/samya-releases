First run

Samaya 2.2 greets new users with three short steps: where your Org files live, which calendars to connect, and how the app should look and plan. Plus a round of small fixes.

Download Changelog

No breaking changes

  • Existing users never see first run: it opens only when no Org folder is set up.
  • Org files and their format are untouched.

Samaya offers the update in Settings › Update; or run the installer again.

Org filesCalendarsPreferencesFixed

Org files

Type or browse to a folder and Samaya checks it as you go: its files and tasks, or that it is empty, missing or read-only, with Use ~/org as the way out. Continue saves it.

Calendars

Connect Google or Outlook accounts with the same form as Settings, or continue without connecting.

Preferences

Pick the theme and accent colour, your capacity per day and the day the week starts on, then Open Today. Skip setup opens Today from any step, asking first if it would create ~/org.

Also in 2.2

  • Progress' Log popover names the measure and the last value logged.
  • Settings search scrolls to the result you move to, and its Clear sits inside the field.
  • All sources shows one sign-in banner per signed-out account, and rows from that account say Signed out.
  • When an add to a channel fails, the composer offers Add to Inbox; an event taken to connect a calendar comes back with its draft.
  • Month cells keep "+N" at small sizes, the New goal form's Channel works from the keyboard, and the shortcut sheet ends on whole rows.
