v2.2.0 · 25 November 2026

First run

If you're new to Samaya, it now walks you through setup the first time you open it. It's three quick steps. Tell it where your Org files live, connect your calendars, and choose how you want it to look and plan. There's also a bunch of small fixes in here.

Download Changelog

No breaking changes

  • Existing users won't see any of this. It only shows up when no Org folder is set up yet.
  • Org files and their format haven't changed.

You'll get the update in Settings › Update, or you can run the installer again.

Org filesCalendarsPreferencesFixed

Org files

Type a folder path or browse to one, and it gets checked while you type. You'll see how many files and tasks it found, or a heads-up if the folder is empty, missing or read-only. If you get stuck, you can always pick Use ~/org. Continue saves it.

Calendars

Connect your Google or Outlook accounts here, using the same form you'd find in Settings. Or skip it for now and continue without connecting.

Preferences

Choose a theme and accent colour, your capacity per day and which day your week starts on, then hit Open Today. You can also hit Skip setup on any step to go straight to Today. If that would mean creating ~/org, it asks you first.

Also in 2.2

  • The Log popover on Progress now tells you which measure you're logging and the last value you logged.
  • Settings search scrolls to the result you move to, and the Clear button is inside the search field now.
  • All sources shows one sign-in banner for each signed-out account, and that account's rows say Signed out.
  • If adding a task to a channel fails, the composer offers Add to Inbox instead. And if a new event sends you off to Settings to connect a calendar, it opens again with your draft when you leave Settings.
  • Month cells keep their "+N" when they're small, Channel in the New goal form works from the keyboard, and the shortcut sheet no longer ends on half a row.
