Settings with pictures

A lot of the calendar settings were hard to understand from their names alone. You'd pick one, go back to the calendar to see what it did, then go back to Settings. Now Settings just shows you a picture of each option. I also added a setting for where logged focus shows up, and task blocks can take their channel's colour.

Download Changelog

No breaking changes

  • Org files and their format haven't changed.
  • Settings you've saved stay as they are. Only new setups start with overlapping activities Side by side.

One shortcut did change. Ctrl B now hides the sidebar, instead of Ctrl \. You'll get the update in Settings › Update, or you can run the installer again.

Settings

In Settings › Scheduling, Time-block colour, Logged focus and Overlapping activities now show each option as a real-size bit of calendar, with the rest of your settings already applied. Click a picture to pick it. Activity bar width has a strip next to the slider that changes as you move it, and the Garmin settings for showing sleep on the calendar get pictures too.

Logged focus

Logged focus has two options now. Beside block is how it worked before, with each session as a hatched box next to its task's block. Inside block is new. It fills the time you logged into the block itself.

Channel colours

Events already had a bar in their calendar's colour. Now task blocks get one in their channel's colour, if you set Time-block colour to By channel.

Mail

Conversations you've already read are greyed out now, so the unread ones stand out. And when you archive or delete the one you're reading, the next one opens, so you can keep going.

Day lane

The Day lane in Week scrolls again when a day has more in it than fits. If a day has hidden events, the lane starts with a count of them, and you can click it to see them.

Also in 2.4

  • In the activity bar, Stripes are now solid bands across the whole bar, and Nested is one unbroken line down the longer activity.
  • The Back button in Settings and Ctrl , take you back to whatever screen you opened Settings from.
  • If a New goal didn't save, quitting used to just lose it. Now it asks you first.
  • Logged focus shows up as hatched boxes again.

Get it

You can grab it from samaya-releases, and the changelog has every change. The keyboard stuff before this was in Samaya 2.3.
